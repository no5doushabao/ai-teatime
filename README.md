# 🍵 AI 讨论会

让几个**真 AI 模型**坐在一张桌子上，围绕一个议题一轮一轮认真讨论 —— 你在旁边听着，随时可以插话。

> ⚠️ **定位：demo / 实验品。** 它能跑、真跑过 60+ 场，但**别指望稳定**：
> 各家模型脾气不一样（推理模型会把 token 花在思考上、有的模型根本看不到图），
> 遇到怪问题欢迎开 issue —— 别拿它干正经活。

![议题选择](docs/screenshot-topic.png)

## 它能做什么

- 🗣 **真模型讨论** —— 接入任意 OpenAI 兼容端点（DeepSeek / 通义千问 / OpenAI / 智谱 / Groq / 本地 Ollama…），
  **Anthropic 官方端点也直接支持**（`/messages` 原生协议自动识别，不用中转）；**谁有 key 谁上场**，没配 key 的灰着
- 📋 **议题制** —— 议题库是**你自己的** `topics.md`（工程自带默认议题 `topics.default.md`，首次运行自动复制一份）；
  打开窗口弹出选择框、**列出全部议题（可滚动）**、**点中哪条就展开「为什么提它」**，每个议题分多轮讨论；
  新加的议题**自动排到第一条**（下次开局就是它）
- 🔁 **接着上次聊** —— 挑到**聊过的**议题时，右下角按钮会从「开始讨论」变成「继续讨论」；
  点下去会把上一次的**两份整理都翻出来**（阿鱼写的逐轮整理 + 会议总览）当这一场的开头，
  **还会把每个人自己上次说过的话接回去**，开场白也明说"这是接着上次继续聊"；
  轮号从上次的下一轮接着数 —— 不是换个人重新聊一遍
- 🧾 **举例子要给出处** —— 提示词里写死了：事件 / 数据 / 论文 / 产品 / 新闻都要给出**可核实的来源**
  （机构或作者 + 标题 + 年份，有网址就附网址）；想不起出处就别当事实讲，**更不许编** ——
  记录员每轮会把「没给出处的例子」单独标出来，一眼看得出谁在张口就来
- ✏️ **改议题** —— 「📋 议题整理」里每一条都能编辑（题目 / 理由 / 由谁提供）；**改过的会标上「（已修改）」**，
  一眼看得出哪条被动过（留痕也写进 `topics.md`）；改了题目的话，往期战绩会跟着改名，不会断链
- 🎚️ **参会者一览** —— 点头像就能拖滑杆调这位 AI 的「思考用量」（还能勾「不限制」）；议题框里另有「预设轮数」，这场跑多久你说了算
- 😴 **让她休息** —— 参会者一览里点一下，这位**这场就不参与**（不发言、也不算进「在场几位」）；
  key、思考用量、她本人的设定全都留着，再点一下就叫回来 —— 想让她歇一场，不用去删配置
- 🔄 **圆桌制** —— 一轮里每人**各发言一次**、等齐了才进下一轮，每轮换人开场
- 🧠 **认真听** —— 每人发言前会读到【本轮已发言的原文】+【前几轮的会议纪要】；提示词要求至少 300 字、有立场有论证、必须点名回应他人
- 📝 **会议纪要** —— 每轮结束由"记录员"模型把有价值的论点（核心论点 / 论据 / 反驳 / 新概念 / 谁改了立场）提炼进一份**全员共享**的历史框，下一轮所有人都读得到
- 🖼 **发图（旁听席）** —— 讨论中往桌上"拍"一张图（选文件 / **Ctrl+V 粘贴** / 拖进窗口都行）：
  **能看图的嘉宾直接看图**；看不到图的会收到一句「你看不到图，别猜」而不是图 —— 不给人装懂的机会。
  图会先在前端压到 1280px 再上传
- 🖼 **议题配图（v0.3.1）** —— 每个议题最多挂 **4 张图**，在「增加议题 / ✏️ 编辑」的弹窗里直接选、**选完立刻预览**
  （每张右上角 ✕ 去掉）；开场白和**每一轮发言**都会带上，换议题不串图
- 🎚 **讨论氛围（v0.3.1）** —— 设置里可选 **🎓 学术研讨**（立场 + 论证 + 点名回应 + 举证纪律，300 字起）
  或 **🍵 轻松聊天**（短句口语、可以接梗吐槽、不用举证点名总结，80 字起）；下一场生效
- ⚠️ **识图提醒（v0.3.1）** —— 选议题弹窗里每条都标「📷 N 张配图」；如果这个议题有图、
  而在座某位的模型**读不了图**，**点「开始讨论」之前**底部就红字警告 —— 别等到开场才发现
- ♻️ **重置 = 真删（v0.3.1）** —— 「📋 议题整理」里的重置会把这个议题的**战绩 + 日志文件一起删掉**
  （删前自动备份到 `_backup/reset-<时间戳>/`）；以前只清战绩、日志还在磁盘上，续场照样读到
- 🍵 **旁观席** —— 你说的话会进下一轮，大家都会看到
- 🛑 **随时叫停 + 会议纪要** —— 觉得聊够了就点「结束议题」；停稳后阿鱼会问你「要我帮你整理会议记录吗？」，
  点「需要」它就汇总出一份结构化纪要（各方立场 / 立场变化及原因 / 主要交锋 / 共识 / 未决问题）

## 快速开始

```powershell
git clone https://github.com/no5doushabao/ai-teatime.git
cd ai-teatime
.\install.ps1        # 一键安装：找 Python + 准备 keys.local.json + 建桌面快捷方式
```

然后**填 API key** —— 两种方式任选：

- ⭐ **推荐**：双击桌面「**AI 讨论会**」→「⚙ 设置」→ 最下面的「**API Key**」里直接粘贴（不用碰文件，界面只显示末四位）
- 或者编辑 `keys.local.json`

⚠️ **至少要有 2 个 key 才开得了场**（`min_guests: 2`，在 `config.local.json` 里改）。
只有 1 个 key 也**可以看**：`python server.py --demo` 是假数据模式，界面照样能逛。

填完就能开场了。

（不想建快捷方式就直接 `.\run.ps1`；`.\run.ps1 -Stop` 关服务。）

| 命令 | 作用 |
|---|---|
| `.\run.ps1` | 起服务 + 开窗口 |
| `.\run.ps1 -Stop` | 关服务 |
| `.\run.ps1 -NoWindow` | 只起服务 |
| `python server.py --selftest` | 自测（86 项，不需要 key） |
| `python server.py --demo` | 假数据模式（验证界面，不需要 key） |

**环境要求**：Windows + Python 3.10+ + Chrome（窗口用的是 `chrome --app` 无边框模式）。除此之外**零依赖** —— 服务端只用 Python 标准库。

**macOS / Linux**：`install.ps1` 和 `run.ps1` 是 PowerShell 脚本，那边用不了 —— 直接

```bash
python3 server.py
```

然后用浏览器打开 <http://127.0.0.1:8765> 就成（没有 `chrome --app` 那种独立窗口，功能一样）。
**所以上面那套「一键」只对 Windows 成立。**

⚠️ **Windows 上如果 `python --version` 报错或一闪就退**：多半装的是**微软商店的占位程序**（在 `WindowsApps` 目录里，是个 0 字节存根，跑起来会报 `9009`）。去 python.org 装一个真的，或者用 `AI_TEATIME_PYTHON` 指定路径。`install.ps1` 会检测这种情况并给出提示。

## 配置

| 想改什么 | 改哪 |
|---|---|
| **API key** | 界面「⚙ 设置 → API Key」直接填（推荐），或改 `keys.local.json` —— 都是**存了即生效，不用重启** |
| **议题** | `topics.md`（**你自己那份，不进 git**）—— 一行 `## 标题` + 正文，加一条就多一个议题；<br>想改「新装时的默认议题」→ `topics.default.md` |
| **每位 AI 的思考用量** | 界面上「👥 参会者一览」里拖滑杆 → 存进 `think-budget.json` |
| **嘉宾 / 模型 / 轮数 / 预算** | `config.local.json`（模板见 `config.example.json`） |

- key 的查找顺序：`keys.local.json` → 同名环境变量 → DSH 的 `~/.dsh/.credentials.yaml`
- ⚠️ `keys.local.json`、`config.local.json`、`think-budget.json`、`topics.md` 都被 `.gitignore` 排除，**别提交**
  （议题特意拆成两份：`topics.md` 会被程序在运行时改写，放进仓库会让 `git status` 一直是脏的）

## 文件

| 文件 | 作用 |
|---|---|
| `server.py` | 本地服务（零依赖，纯标准库）：SSE 推送、圆桌编排、模型调用、记录员 |
| `static/index.html` | 界面（深色 QQ 风 + 议题弹窗 + 议题库 + 参会者一览 + 长文折叠 + 纪要卡片） |
| `topics.default.md` | 工程自带的**默认议题**（首次运行会复制成 `topics.md`） |
| `topics.md` | ⭐ **你自己的议题库** —— 界面上的增删改排序都改它；运行时数据，**不进 git** |
| `config.example.json` | 嘉宾名单 / 角色卡 / 讨论要求 / 轮数 / 预算 |
| `keys.example.json` | key 模板 |
| `gen_avatars.py` · `import_avatars.py` | 生成像素头像 / 把立绘裁成圆形头像 |
| `run.ps1` | 一键启动 |
| `install.ps1` | 一键安装（找 Python / 准备 key 文件 / 建桌面快捷方式） |
| `assets/ayu.ico` | 快捷方式用的图标 |
