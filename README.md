# 🍵 AI 讨论会

阿包 2026-10-10 起意的项目：**让几个真 AI 坐在一张桌子上，围绕预设议题一轮一轮地认真讨论**，他在旁边听、随时插话。

> 最初的想法是"AI 茶话会"（随便聊聊），跑完第一版后阿包提了明确要求，于是改造成了**议题讨论会**。他的四条原话：
>
> 1. 几位 AI 是针对各种问题**各抒己见、一轮一轮讨论**，不是随便说些什么话闲聊
> 2. 我这边有一些设想好的议题，每次启动聊天之后开始讨论，每个话题进行 **10~20 轮**
> 3. 大家的回应要**更加深思熟虑**，而不是短短的一行字
> 4. 要确保每个 AI 都**认真听完了剩下四个 AI 的所有发言，再进行发言**

## 怎么跑

```powershell
.\run.ps1              # 起服务 + 开独立窗口（有 key 就真讨论，没有进 demo）
.\run.ps1 -Stop        # 关服务
.\run.ps1 -NoWindow    # 只起服务
```

窗口是 **Chrome `--app` 模式**（没有地址栏/标签页，像个独立小应用）。
⭐ URL 带时间戳，所以**改了界面不用手动清缓存**。

**启动后的流程**：打开窗口 → 弹出**议题选择框** → 选一个 → 点「开始讨论」→ 阿鱼开场主持 → 一轮一轮讨论。

## 配 key

```powershell
copy keys.example.json keys.local.json     # 填进去，保存即生效（不用重启 DSH）
```

- key 查找顺序：`keys.local.json` → 同名环境变量 → **DSH 的 `~/.dsh/.credentials.yaml`**
  （⭐ 所以 DeepSeek 那家不用额外配，DSH 里本来就有）
- `keys.local.json` 已被 `.gitignore` 排除；`config.local.json` 同理
- 想加分/改模型/改轮数 → 编辑 `config.local.json`（模板 `config.example.json`）
- 想加减议题 → 编辑 **`topics.md`**（`## 标题` 一行 + 正文，程序靠它分段）

## 设计要点

**① 议题制（不是闲聊）**
议题从 `topics.md` 读，界面弹窗选择。议题的完整正文会进上下文。

**② 圆桌制 · 起点轮转**
一轮里每人**各发言一次**，等齐了才下一轮；每轮换人开场（免得永远同一个先说话）。
**不是**"A 说→B 立刻回 A→C 立刻回 B"的链式雪球。

**③ 深思熟虑**
提示词要求 300 字起、有立场有论证、必须点名回应他人；`max_tokens` 给到 4000。
实测每人每次 **1200~2000 字**。

**④ 公用历史框（阿鱼的活儿）**
每轮结束，**阿鱼（DeepSeek）额外跑一次"会议记录员"**，把本轮里真正有价值的想法
（核心论点 / 关键论据 / 有力反驳 / 新概念 / 谁改了立场）提炼成分条要点，写进一份**全员共享**的历史框。
下一轮每个人发言时都会读到它。

**⑤ 分层上下文**（阿包拍板的方案）
每个 AI 发言时收到的内容 =

```
【议题 + 讨论要求】
【公用历史框 · 前几轮要点】   ← 阿鱼整理的，全员共享
【本轮已发言 · 原文】          ← 一字不落，保证"听全了同桌这一轮的每个人"
【你自己的历次发言】           ← 防原地打转，允许深化
【现在轮到你】
```

**⑥ 身份纪律**
prompt 硬性要求"只能代表自己发言、不许替别人写、不许用别人口吻、不许在开头写【某某】"；
外加兜底：万一模型越位，`strip_leading_tag()` 会把开头的标签剥掉。

**⑦ 默认不自动开场**
双击启动器只是"把场子支起来"（阿鱼喊停过一次服务 —— 不想它自己烧额度）。
想做实验就点窗口里的「🍵 开场」。`config` 里 `auto_start: true` 可恢复自动。

| 元素 | 说明 |
|---|---|
| **议题弹窗** | 每次打开窗口就弹；列出所有议题，可点选；人数不够时按钮灰掉并提示还差几位 |

## 踩过的坑（都修了，别再踩）

1. ⚠️ **浏览器缓存**：改完界面一直显示旧页。而且 `Invoke-WebRequest` 自己也有缓存（会骗你"文件没更新"）
   → **验证网页内容用 `curl`**；界面靠"URL 带时间戳"根治。
2. ⚠️ **推理模型的思考 token 计入 `max_completion_tokens`**：GPT-5 系列设 1200 时，思考就吃光额度 →
   **返回空串**（界面上表现成"卡住不出声"）。给到 4000。
3. ⚠️ **各家参数不统一**：GPT-5 不收自定义 `temperature`，也不收 `max_tokens`（要 `max_completion_tokens`）
   → `llm_call()` **穷举几种参数组合**，撞到"不支持"就换，命中后缓存。
4. ⚠️ **空回复必须报警**：以前返回空串就"说"了句空话 → 现在自动 3 倍预算重试 + 兜底提示。
5. ⚠️ **配置缓存**：`settings` 是启动时读一次的，界面上换了议题、后端还在聊旧的
   → 按下「开场」时**重新读配置**。
6. ⚠️ **模型会"越位"**：替别人发言、开头写【某某】→ prompt 加"身份纪律" + 剥离兜底。
7. ⚠️ **`.ps1` 必须存成 UTF-8 with BOM**：PowerShell 5.1 按 GBK 读，中文注释会把语法撑坏
   （`ParserError: Unexpected token`）。⭐ **用 `edit` 工具改完 `.ps1` 要重新加 BOM**（`encoding='utf-8-sig'`）。
8. ⚠️ **改代码时手滑**：`old_string` 只写"函数头 + 下一行"、`new_string` 只写"函数头"，
   **等于在删中间的行**。插入代码时两边都要包含完整的原代码；改完立刻跑自测。
