## 0. 三十秒看懂

**它是什么**：几个**真的 AI 模型**围着一张桌子，围绕一个**议题**一轮一轮认真讨论；你在旁听席上听，可以随时插话。

```
   你（旁听席）
       │ 说一句话 → 进下一轮，所有人都看得到
       ▼
 ┌─────────────────────────────────┐
 │  第 N 轮：每人各说一次（约 300 字） │
 │  阿鱼当记录员，把要点写进公用历史框  │
 └─────────────────────────────────┘
       │  手动：停下等你点「开始下一轮」
       │  自动：一口气跑完
       ▼
   结束 → 问她「要不要整理会议纪要」
```

**适合**：想听多个模型就一个话题**认真吵一架**；想看看不同家的风格差异。
**不适合**：要准确答案（会胡说的）、要稳定生产（它是 demo）、怕花 token 的。

> ⚠️ 官方定位就是 **demo / 实验品**。别拿它干正经活。

## 1. 装起来

### Windows（一键）

```powershell
git clone https://github.com/no5doushabao/ai-teatime.git
cd ai-teatime
.\install.ps1        # 找 Python + 生成 keys.local.json + 建桌面快捷方式
```

`install.ps1` 做三件事：

1. 找可用的 Python（会**真的跑一次 `--version`** —— 微软商店那个 0 字节存根会被识破并提示）
2. 从 `keys.example.json` 复制一份 `keys.local.json`
3. 在桌面建「AI 讨论会」快捷方式（图标 `assets/ayu.ico`）

### 环境要求

| 项 | 要求 |
|---|---|
| 系统 | **Windows**（`install.ps1` / `run.ps1` 是 PowerShell）；macOS/Linux 见下 |
| Python | **3.10+** |
| 浏览器 | **Chrome**（窗口用的是 `chrome --app` 无边框模式；没装也能跑，只是没有独立窗口） |
| 依赖 | **零** —— 服务端只用 Python 标准库 |

**macOS / Linux**：直接 `python3 server.py`，然后浏览器打开 <http://127.0.0.1:8765>。

### 填 API Key（两种方式，任选）

- ⭐ **推荐**：双击「AI 讨论会」→「**⚙ 设置**」→ 最下面「**API Key**」→ 粘贴 → 回车
  （界面只显示末四位；key 不会被回传到浏览器，也不进日志）
- 或者直接编辑 `keys.local.json`

⚠️ **至少要配 2 个 key 才开得了场**（`min_guests: 2`，可在 `config.local.json` 改）。
只有一个 key 也能看界面：`python server.py --demo`（假数据模式，不花钱）。

## 2. 第一次开场（三步）

1. 双击桌面「**AI 讨论会**」→ 自动弹出**议题选择框**
2. 挑一条议题 → 点右下角「**开始讨论**」
3. 想让它自己跑完就点 footer 的「**⚡ 自动**」；想一轮一轮来就每轮点「**▶ 开始下一轮**」

> 默认**不自动开场** —— 双击只是"支起场子"，什么时候开始你说了算。

## 3. 界面导览

### 3.1 顶部：议题条

```
📌 今晚讨论什么…        [⚙ 设置] [📋 议题整理] [👥 参会者一览] [🍵 开场 / 换议题]
```

| 按钮 | 干什么 |
|---|---|
| **⚙ 设置** | 关窗口自动结束 / 默认自动模式 / 你的称呼 / 讨论氛围 / 检查更新 / API Key / 添加嘉宾 |
| **📋 议题整理** | 议题库：拖排序、增删改、重置战绩、现场提问 |
| **👥 参会者一览** | 每位嘉宾：思考用量、模型、休息、主持人、头像、编辑、删除 |
| **🍵 开场 / 换议题** | 打开**议题选择框**（也用来换议题） |

### 3.2 中间：讨论流

每条消息显示「**时间 + 谁 + 正文**」。系统消息（灰字）告诉你发生了什么：
开场白、第几轮、纪要写入、谁掉线、切到自动…

- 发言很长会**折叠**，点开看全文
- 每条发言可以**复制**，里面的链接**能直接点开**（方便你自己核真伪）
- 会议纪要会渲染成一张**蓝色大卡片**

### 3.3 底部：旁听席

```
💬 旁听席（你）—— 说的话会进下一轮，大家都会看到
[⚡ 自动] [📜 往期讨论] [🛑 结束议题]
[🖼] [说点什么…（Enter 发送 · Shift+Enter 换行）] [发送]
```

| 元素 | 说明 |
|---|---|
| **输入框** | Enter 发送、Shift+Enter 换行；输入框会**向上长高**，不会往右无限延伸 |
| **🖼** | 发图：点它选文件 / **Ctrl+V 粘贴** / **拖进来**都行（前端先压到 1280px） |
| **⚡ 自动** | 点亮 = 一口气跑完；再点 = 切回手动 |
| **📜 往期讨论** | 看以前每一场的纪要 / 完整记录，可导出 |
| **🛑 结束议题** | 停（当前这位说完才停，不硬中断）→ 然后问你要不要整理纪要 |

## 4. 一场讨论怎么跑

### 4.1 圆桌制

- 一轮里**每人各发言一次**，等齐了才进下一轮
- **每轮换人开场**（起点轮转），不会永远是同一个先开口
- **第一轮由「命题人」先发言**（议题是谁提的；他不在场就按名单轮转）

### 4.2 手动 / 自动

| 模式 | 行为 |
|---|---|
| **手动**（默认） | 每轮纪要写完就**停下**，聊天流里出现「▶ 开始下一轮」，点了才继续 |
| **自动** | 一口气跑到预设轮数或预算用完 |

可以在「⚙ 设置 → 默认自动模式」里把**下一场**的默认值改掉。

### 4.3 你插话

在旁听席说一句话 → 会在**下一轮开头**被所有人正面回应（也会进他们的上下文）。

### 4.4 结束与总结

点「🛑 结束议题」后：

1. 当前正在说话的那位**把话说完**（不硬中断，避免留下半句话）
2. 系统问你「**要我帮你整理会议记录吗？**」
3. 点「**需要，帮我整理**」→ 生成**结构化会议纪要**：
   各方立场 / 立场变化及原因 / 主要交锋 / 共识 / 未决问题

> ⚠️ **不点就没有总览** —— 只有每轮的「逐轮纪要」，没有整场总结。

## 5. 管议题

### 5.1 议题从哪来

- **`topics.md`** —— 你自己那份（界面上的增删改排序都改它，**不进 git**）
- **`topics.default.md`** —— 工程自带的默认议题（首次运行会复制成 `topics.md`）

格式：`## 标题` 一行 + 正文（可多行）＋ 可选的「由谁提供」。

### 5.2 📋 议题整理（弹窗里能做什么）

| 操作 | 说明 |
|---|---|
| **拖动排序** | 松手即写回议题库 |
| **✏️ 编辑** | 改题目 / 理由 / 由谁提供；改过的会标「（已修改）」 |
| **🗑 删除** | 删掉这条议题 |
| **♻️ 重置** | ⚠️ **v0.3.1 起是真删**：这个议题的**战绩 + 日志文件一起删**（删前自动备份到 `_backup/reset-<时间戳>/`） |
| **➕ 增加议题** | 题目（单行）→ 选题理由（大框）→ 由谁提供；**加完自动排到第一条**（下次开局直接是它） |
| **🖼 配图** | 每个议题最多 **4 张图**，选完立刻预览，右上角 ✕ 去掉。开场白和**每轮发言**都会带上 |
| **🎤 现场提问** | 选一位在座的 AI，让它提 1~3 个**带理由**的议题备选，直接「添加」进库 |

### 5.3 议题框里还有两样

- **预设轮数**（底部小输入框）：这场跑多少轮，**松手才发请求**
- **每条议题上的标记**：`由 XXX 提供 · 已讨论 N 轮 · 参与者：… · 📷 N 张配图`

## 6. 管嘉宾

### 6.1 👥 参会者一览（核心面板）

点任意头像 → 下方展开这位的全部设置：

| 设置 | 说明 |
|---|---|
| **模型** | 下拉选它用哪个模型；旁边「🔄 **更新模型选单**」= 现场去这家 `/models` 查一遍（新出的模型会出现在下拉里） |
| **思考用量** | 滑杆 **1000~16000** + 「不限制」勾选框。⚠️ 这是 `max_tokens` —— 推理模型**思考 + 正文共用这一份**，给少了会返回空串 |
| **参与状态** | 「😴 让她休息」= 这场不参与（不发言、不算进在场人数），再点叫回来 |
| **主持人** | 「👑 选她当主持 / 取消主持」。**主持人负责：开场白 + 每轮纪要 + 会议总结** |
| **头像** | 「🖼 换头像」→ 自动裁成 256×256。没设过的显示**默认问号** |
| **这位嘉宾** | 「✏️ 编辑资料」（昵称 / 接口地址 / 模型名 / 小字 / 换 key）· 「🗑 删除」（连带清 key 和头像） |

**卡片上的角标**：`👑 主持` / `😴 休息中` / `未配 key`（灰着 = 没 key，上不了场）

### 6.2 ➕ 添加一位 AI（⚙ 设置 → 最下面）

填五项：**昵称 / 接口地址 / 模型名 / 小字（可选）/ API Key（可稍后填）**。

⚠️ **接口地址要填 API 地址**，不是浏览器里那个网页的地址：

| ✅ 对 | ❌ 错 |
|---|---|
| `https://api.deepseek.com` | `https://chat.deepseek.com/…?model=…` |
| `https://xxx.com/v1` | 带 `?` 的、带 `/experience/` 的网页链接 |

界面上会拦这种错误并提示你去**服务商控制台的「API Key / 快速开始」页复制 Base URL**。

保存后**下一场开局就上桌**（不用重启）。

### 6.3 嘉宾从哪来 / 换人

- 嘉宾名单在 `config.local.json` 的 `guests` 数组（模板见 `config.example.json`）
- **谁有 key 谁上场**；没 key 的显示但灰着
- 想改昵称、模型、接口：用界面的「✏️ 编辑资料」，别手改 JSON（容易漏字段）

## 7. 设置项全表

「⚙ 设置」弹窗里，从上到下：

| 设置 | 选项 | 生效时机 |
|---|---|---|
| **关闭窗口后立即结束** | 开 / 关（默认关） | 立即。开 = 界面关了就不再往下跑（当前这位说完收尾）；⚠️ 刷新页面不算关窗口，会等 90 秒确认 |
| **默认自动模式** | 开 / 关（默认关） | 下一场。开 = 开场就直接「⚡ 自动」跑完 |
| **你的称呼** | 文本（默认「你」） | 下一场。AI 们怎么叫你（以前写死的是"阿包"） |
| **讨论氛围** | 🎓 学术研讨 / 🍵 轻松聊天 | **下一场**。学术 = 300 字起、要举证点名；轻松 = 80 字起、可以接梗吐槽 |
| **检查更新** | 按钮 | 查 GitHub 有没有新版，有就告诉你在项目目录跑 `git pull` |
| **API Key** | 每位一个密码框 | 立即（下一场开局就用） |
| **添加一位 AI** | 表单 | 下一场 |

### 配置文件里还有（`config.local.json`）

| 字段 | 默认 | 作用 |
|---|---|---|
| `rounds` | 12 | 默认预设轮数（界面上的输入框可以临时覆盖） |
| `budget_cny` | 5.0 | 预算上限，超了**自动散会** |
| `gap_seconds` | `[2, 5]` | 两位发言之间随机停顿几秒（像真人节奏） |
| `min_guests` | 2 | 至少几位有 key 才允许开场 |
| `debate.style` | — | 发言要求（学术氛围下用这段） |
| `debate.max_tokens` | 4000 | 默认思考用量 |
| `debate.recorder_persona` | — | 记录员的提示词 |
| `debate.host_persona` | — | 主持人的提示词 |

> ⚠️ 改 `config.local.json` 里的**嘉宾 / 模型**要**重启服务**；改界面上的设置不用。

## 8. 续场 / 往期 / 导出

### 8.1 接着上次聊

在议题选择框里挑一条**聊过的**议题 → 右下角按钮会变成「**继续讨论**」。

点下去会发生：

- 把上一次的**两份整理**（逐轮纪要 + 会议总结）翻出来当这一场的开头
- 把**每个人自己**上次最后两段发言接回去
- **轮号从上次的下一轮接着数**（预设轮数 = 这个议题聊到第几轮为止）
- ⚠️ **换人续场**：这场才加入的嘉宾会被明确告知「你是中途加入的」—— 不会假装参加过前面的轮次

### 8.2 📜 往期讨论

列出每一场的：议题 / 轮数 / 参与者 / 时间；点进去看**纪要**或**完整记录**，可以「📥 **导出 .md**」下载。

### 8.3 文件在哪

每场讨论的完整记录：`logs/<日期-时间-议题>.md`

## 9. 常见问题

### ❓ 点「开始讨论」没反应 / 提示人不够

至少要有 **2 位有 key 的嘉宾**（`min_guests`）。去「⚙ 设置 → API Key」看谁还是「未配置」。

### ❓ 某位嘉宾一直不说话 / 说几句就停

- 它可能**撞限流**了（429）→ 日志里会有「连续失败，先不请他了」，本场自动请下场，不影响别人
- 也可能是**思考用量给太少**：推理模型的思考 token 和正文共用一份额度，给 1200 它光思考就用完了。**调到 8000** 试试
- 模型名/接口地址填错 → 401 / 404，一样会被请下场

### ❓ 说「没有主持人」

主持人是**可选**的，但没主持人时：

- ❌ 没有开场白
- ❌ 没有每轮纪要（公用历史框不更新）
- ❌ 没有会议总结

**→ AI 们容易重复发言、忘掉别人说过什么。** 开场前界面会弹框确认，你确认了才开。
去「👥 参会者一览 → 👑 选她当主持」随便指一位就行。

### ❓ 模型下拉里显示「⚠️ 可能已弃用」

说明这位现在用的模型**不在服务商返回的可用清单里**（比如 DeepSeek 的 `deepseek-chat` 已经不在列表里了）。
点下拉换一个，或者先点「🔄 更新模型选单」重新查一次。

### ❓ 「更新模型选单」报错

- **401** = key 不对，或者这个 key 不属于这个接口地址
- **连不上** = 接口地址写错了（常见：填成了网页地址）
- 每次**启动服务**时会自动把所有嘉宾查一遍，所以列表通常是新鲜的

### ❓ 讨论里有人看不到图

每位嘉宾的模型**能不能读图**是分开判断的：

- 能读：直接看图
- 不能读：会收到一句「你看不到图，别猜」而不是图（**不给人装懂的机会**）
- 选议题时，如果有配图但某位读不了，**开场前**就红字提醒你

### ❓ 聊太贵了怎么办

- 看「⚙ 设置」旁边/系统消息里的花费提示，或者看每场结束的「粗估 N tokens」
- 调小 `budget_cny`（超了自动散会）
- 把「思考用量」调低（但别低于 2000，推理模型会空回复）
- 用便宜模型：模型下拉里选 flash / mini 那种

### ❓ 怎么更新到新版本

「⚙ 设置 → 🔄 检查更新」查一下，有新版本就在项目目录跑：

```powershell
git pull
```

> ⚠️ 如果你自己改过插件/源码，`git pull` 可能冲突 —— 先 `git stash` 或备份。

### ❓ 界面卡住 / 点了没反应

先看服务还在不在：`.\run.ps1 -Stop` 再 `.\run.ps1`。
（macOS/Linux：杀掉 `python3 server.py` 再起。）

## 10. 数据在哪 / 隐私

**全部在本地，不上传任何地方**（除了你自己的模型 API 请求）。

| 文件 / 目录 | 内容 | 进 git 吗 |
|---|---|---|
| `config.local.json` | 嘉宾名单 / 模型 / 轮数 / 预算 | ❌ |
| `keys.local.json` | 各家 API Key | ❌ **绝不** |
| `topics.md` | 你的议题库 | ❌ |
| `think-budget.json` | 每位嘉宾的思考用量 | ❌ |
| `host.json` | 谁是主持人 | ❌ |
| `model-catalog.json` | 探测到的可用模型清单 | ❌ |
| `afterglow.json` | 讨论「余味」（待机闲聊时的记忆） | ❌ |
| `debate-history.json` | 每场战绩 | ❌ |
| `resting.json` | 谁在休息 | ❌ |
| `logs/` | 每场讨论的完整记录 | ❌ |
| `shots/` | 你发的图 | ❌ |
| `avatars-user/` | 你上传的头像 | ❌ |

**要备份**（换电脑/重装前）：把上面这些**非 git 文件**拷走就行。

**隐私提醒**：

- key 只在本地，界面只显示末四位
- 你发的图、说的话会进对应模型的 API 请求（各家政策不同，自己判断）
- 讨论记录里可能包含你输入的敏感内容 —— `logs/` 不上传，但**别把 `logs/` 提交到任何仓库**

## 11. 命令速查

| 命令 | 作用 |
|---|---|
| `.\run.ps1` | 起服务 + 开窗口 |
